# LazyBoard 🦥 — ขี้เกียจสลับภาษาโว้ย

แอป menu bar บน macOS: พิมพ์ค้างคีย์บอร์ดผิดภาษา พิมพ์ผิด ก็ปล่อยไป เดี๋ยวแก้ให้เอง

แอป menu bar ที่คอยดูสิ่งที่พิมพ์ทั้งเครื่อง ถ้าพบว่าพิมพ์ไทยค้างคีย์บอร์ดอังกฤษ
(เช่น `mujgdujp;-hv'` = ที่เกี่ยวข้อง) หรือกลับกัน จะโชว์คำที่แก้แล้ว กด **Tab** เพื่อแทนที่
และสลับคีย์บอร์ดให้อัตโนมัติ ทำงาน offline ใช้พจนานุกรมของ macOS ไม่ต้องใช้ LLM/API key

## วิธีใช้

```bash
./build.sh            # ได้ build/LazyBoard.app
open build/LazyBoard.app
```

1. เปิดครั้งแรกระบบจะถามสิทธิ์ **Accessibility** ให้ไปติ๊ก LazyBoard ใน
   System Settings → Privacy & Security → Accessibility (แอปรอจนได้สิทธิ์แล้วเริ่มทำงานเอง)
2. พิมพ์ตามปกติ ถ้าพิมพ์ค้างภาษาผิด จะมี popup โชว์คำที่แก้แล้วใต้เคอร์เซอร์เมื่อหยุดพิมพ์ครู่หนึ่ง (ครึ่งวินาที)
3. กด **Tab** เพื่อแทนที่ (คีย์บอร์ดจะสลับเป็นภาษาที่ถูกให้ด้วย ปิดได้ในเมนู)
4. ไม่อยากแก้ก็พิมพ์ต่อไปเฉยๆ popup หายเองเมื่อกด Enter/ลูกศร/คลิก

เมนูที่ไอคอนคีย์บอร์ดสายฟ้าบน menu bar (ชั้นแรกมีแค่ที่ใช้บ่อย): เปิด/ปิด, ตรวจด้วย Claude ก่อนส่ง,
เติมอีโมจิ, ไม่ใช้ในแอปที่เปิดอยู่, แบบทดสอบการพิมพ์ ส่วน "ตั้งค่าเพิ่มเติม" มี สลับคีย์บอร์ดหลังแก้,
แก้ให้เองตอนเคาะ space/Enter, ตรวจเงียบๆ ระหว่างพิมพ์, backend/โมเดล/API key, เปิดตอน login, Accessibility

## แก้ให้เองโดยไม่ต้องกด Tab (เฉพาะพิมพ์ค้างคีย์บอร์ด)

เปิดอยู่เป็นค่าเริ่มต้น เมื่อเคาะ **space** หรือกด **Enter** แล้วท่อนท้ายเป็นข้อความพิมพ์ค้างคีย์บอร์ดที่มั่นใจ
(มีคำที่ตัดสินได้แน่อย่างน้อยหนึ่งคำ) แอปจะแทนที่ให้ทันทีไม่ว่าสั้นยาว (ที่ จะ 10 PR login …) และสลับคีย์บอร์ดให้
จึงพิมพ์ทุกอย่างบนคีย์บอร์ดเดียวโดยไม่ต้องสลับเองได้เลย ถ้าแปลงผิด กด **Esc ภายใน 4 วินาที** ข้อความเดิมจะกลับมา
และคำนั้นจะไม่ถูกแปลงอีกจนกว่าจะเปิดแอปใหม่ ปิดได้ในเมนู
ส่วน typo ที่ให้ Claude แก้ยังต้องกด Tab เสมอ เพราะผลมาช้าและอาจเดาผิด
ยกเว้น typo ไทยยอดฮิตที่ตัดสินได้แน่ แก้ให้เองตอนเคาะ space เช่นกัน (`ThaiTypos.swift`):
้ แทน ็ ในคำประจำวัน (เป้น→เป็น ก้→ก็ เด้ก→เด็ก), เเ→แ, ๋ แทน ่ (ไม๋→ไม่) ยกเว้นคำที่ใช้ ๋ จริง

## อม Enter ไว้ตรวจก่อนส่ง

เปิดอยู่เป็นค่าเริ่มต้น เมื่อกด Enter แล้วบรรทัดล่าสุด (≥4 ปุ่ม) ยังไม่เคยถูก Claude ตรวจ แอปจะ **ยังไม่ส่ง**
(ตอนกด Enter แอปอ่านข้อความจริงในช่องผ่าน Accessibility ด้วย จึงตรวจได้แม้เคยคลิกเมาส์หรือกดลูกศรระหว่างพิมพ์
ขอแค่เคอร์เซอร์อยู่ท้ายข้อความ) ถ้ามีคำแก้จากการตรวจเงียบๆ ค้างอยู่ Enter ครั้งแรกจะไม่ส่ง: Tab แก้ หรือ Enter อีกครั้งเพื่อส่งตามเดิม
ขึ้น "⏳ ตรวจก่อนส่ง…" แล้วส่งประโยคไปตรวจทันที
- ระหว่างตรวจจะเห็นจุดสามจุดเด้งไล่กัน
- ไม่มีอะไรต้องแก้ → ขึ้น ✓ สั้นๆ แล้วส่ง Enter ให้เองทันที
- มีคำแก้ → ขึ้นคำแก้ให้เลือก: **Tab** = แก้ข้อความในช่อง (ยังไม่ส่ง กด Enter เองเมื่อพอใจ ไม่ตรวจซ้ำ),
  **Enter** = ส่งตามเดิม (Enter ภายใน 1.5 วิหลังคำแก้โผล่ถูกเมิน กันกดรัวแล้วส่งทับ), **Esc** = ยกเลิกไม่ส่ง
- กด Enter ซ้ำระหว่างรอ = ยังรอต่อ (ไม่ส่ง), Esc = ยกเลิก, พิมพ์ต่อ = ยกเลิกการอม, ตรวจไม่ทันใน 10 วิ = บอกแล้วให้กด Enter เอง
- **Ctrl+Enter** = ส่งทันทีตามที่พิมพ์ ไม่ตรวจ ไม่แก้อะไรเลย (สำหรับ password, ลิงก์, โค้ด)
- **Shift/Cmd/Option + Enter** = ขึ้นบรรทัดใหม่ในข้อความ ไม่อม ไม่ส่งตรวจ (แก้พิมพ์ค้างคีย์บอร์ดที่มั่นใจให้ก่อนถ้ามี)
  การตรวจตอนกด Enter จริงจะดูเฉพาะบรรทัดล่าสุด
- ค่าเริ่มต้น Claude ตรวจ **เฉพาะตอนกด Enter** ระหว่างพิมพ์จะไม่มีการส่งไปตรวจ (เปิด "ตรวจเงียบๆ ระหว่างหยุดพิมพ์" ในเมนูได้ถ้าต้องการ)
ข้อความที่ส่งไปตรวจจะมี "คำใบ้เลย์เอาต์" แนบไปด้วย: คำที่ไม่ใช่คำจริงในภาษาของมันจะถูกแปลงเป็นอีกเลย์เอาต์ให้
Claude เห็น (เช่น กยสนั → dploy, พำฟกทำ → readme) จึงแก้เคส "พิมพ์ค้างเลย์เอาต์ + typo พร้อมกัน" ได้

## แบบทดสอบการพิมพ์

เมนู → "แบบทดสอบการพิมพ์…" จะได้หน้าต่างให้พิมพ์ตามประโยค 10 ประโยค (ไทยสลับอังกฤษ) กด Enter เพื่อส่ง
คะแนนต่อประโยค = 1 − ระยะ Levenshtein ÷ ความยาว (ตัดช่องว่างหัวท้าย) พร้อมเวลาและจำนวน fix ที่ใช้
(L = เลย์เอาต์, ✨ = Claude) ท้ายสุดสรุปความถูกต้องเฉลี่ยและจำนวนประโยคที่ตรงเป๊ะ
ระหว่างทดสอบ popup และ Tab ทำงานตามปกติ จึงวัดได้ทั้ง "พิมพ์เองถูกแค่ไหน" และ "ทูลช่วยได้แค่ไหน"
ผลละเอียดรายประโยค (ต้นฉบับ/ที่พิมพ์) ถูกบันทึกต่อท้ายที่ `~/Library/Application Support/LazyBoard/typing-test-results.txt`

## ชั้น LLM: แก้คำผิดจริงด้วย Claude (ไม่บังคับ)

ตัวแก้เลย์เอาต์ทำงาน offline เสมอ ชั้นนี้เสริมสำหรับ typo แบบ "อังดฤา" → อังกฤษ, "เรยล" → เลย
เรียก Claude ได้สองทาง เลือกในเมนู "เรียก Claude ผ่าน"

**ทางที่ 1 (ค่าเริ่มต้น): Claude Code CLI** ไม่ต้องมี API key ใช้ login ของ Claude Code ที่มีในเครื่องอยู่แล้ว

- ต้องมีคำสั่ง `claude` (ติดตั้งมากับ Claude Code) และเคย login จาก Terminal แล้ว
  ถ้ายัง ให้เปิด Terminal พิมพ์ `claude` แล้วสั่ง `/login` หนึ่งครั้ง
- แอปเปิด `claude -p --input-format stream-json --output-format stream-json …` ค้างไว้หนึ่ง process
  (เริ่มตั้งแต่แอปเปิด) แล้วส่งข้อความเข้าไปทีละบรรทัด จึงไม่เสียเวลา startup ทุกครั้ง
  รันจากโฟลเดอร์ว่าง ปิด tools/MCP จึงไม่โหลด CLAUDE.md ของโปรเจกต์ใดๆ
  process ถูกเปิดใหม่ทุก 25 ข้อความ (กัน context โต) และปิดเองเมื่อไม่ใช้ 10 นาที
- ใช้เวลาราว 3 วินาทีต่อครั้ง (ครั้งแรกหลังเปิดราว 4–5) และนับรวมในโควตาการใช้งาน Claude ของบัญชี
  (5-hour limit เดียวกับที่ใช้แชท)

**ทางที่ 2: Claude API key** เร็วกว่า (ราวครึ่งวินาที) แต่ต้องมีบัญชี platform.claude.com ที่เติมเครดิต

1. สร้างคีย์ที่ platform.claude.com → API Keys
2. เมนู LazyBoard → "เรียก Claude ผ่าน" → Claude API key แล้ว "ตั้งค่า Claude API key…" (เก็บใน Keychain)

**การทำงานเหมือนกันทั้งสองทาง:** พิมพ์แล้วหยุดราว 1 วินาที ส่งเฉพาะประโยคล่าสุด (ไม่เกิน ~160 ปุ่ม)
ถ้า Claude เห็น typo จะมี popup "✨ ข้อความที่แก้" กด Tab เพื่อแทนที่ (ไม่สลับคีย์บอร์ด)
Claude ถูกสั่งให้แก้ทุกคำที่ไม่ใช่คำจริง (ไทย/อังกฤษ) ให้เป็นคำที่น่าจะตั้งใจพิมพ์ตามบริบท
ถ้าคำไหนกำกวม จะส่งทางเลือกมาด้วย (ไม่เกิน 2 แบบ) popup แสดงทุกแบบ กด Tab ใช้แบบแรก
แล้ว **กด Tab ซ้ำภายใน 6 วินาที** เพื่อสลับไปแบบถัดไป (ข้อความที่แทนไปแล้วจะถูกเปลี่ยนให้)
คำขอที่กำลังรอคำตอบจะไม่ถูกยกเลิกเมื่อพิมพ์ต่อ แต่ผลจะถูกทิ้งถ้าไม่ตรงกับข้อความล่าสุดแล้ว
ไม่ส่งถ้าตัวแก้เลย์เอาต์มีคำแนะนำอยู่แล้ว ไม่ส่งในแอปที่ติ๊ก "ไม่ใช้ในแอปนี้" ผลที่เก่ากว่าสิ่งที่พิมพ์ไปแล้วถูกทิ้ง
โมเดลเริ่มต้น Haiku 5.5 เปลี่ยนเป็น Opus 5.5 ได้ในเมนู "โมเดล"

ทดสอบจาก terminal:

```bash
./build/LazyBoard.app/Contents/MacOS/LazyBoard --llm "เนี่ยภาษาอังดฤายังผิดอยู่เรยล"
```

(`LAZYBOARD_BACKEND=api` เพื่อทดสอบทาง API key, `LAZYBOARD_MODEL=claude-opus-5-5` เพื่อเปลี่ยนโมเดล)

## กฎที่ช่วยจับอังกฤษที่พิมพ์บนคีย์บอร์ดไทย

- คำไทยลงท้ายด้วย ั หรือ ื ไม่ได้ (login = สนเรื, deploy = กำยสนั จึงถูกจับทันที) และ ็ ลงท้ายได้เฉพาะ ก็
- เครื่องหมายที่คีย์บอร์ดไทยพิมพ์ออกมาเอง (? จาก Shift+M, ( ) , . % + _ / -) นับเป็นส่วนหนึ่งของคำไทย
  (README = ฑฎฤฏ?ฎ)
- ตัวย่อที่กด Shift บนคีย์บอร์ดไทย (PR = ญพ): พยัญชนะชั้น Shift ไม่มีสระ และแปลงได้เป็นคำที่รู้จัก → แปลงทันที
- ปุ่มที่สะกดเป็นคำอังกฤษในพจนานุกรมยาว ≥5 ตัว (script = หแพรยะ) → แปลงทันทีแม้ฝั่งไทยจะผ่านอักขรวิธี
- คำไทยสั้นที่พบบ่อยซึ่งปุ่มบังเอิญเป็นคำอังกฤษ 2 ตัว (รอ = iv, ที = mu) → แปลงทันที
- พิมพ์ค้างเลย์เอาต์และสลับตัวอักษรพร้อมกัน (หแรพยะ = scirpt) ตัวตรวจไม่กล้าตัดสิน แต่ส่งคำใบ้ให้ Claude แก้ตอน Enter

## กันแจ้งเตือนผิดกับคำอังกฤษ

- คำ dev/product ที่พจนานุกรม macOS ไม่รู้จัก (google, github, staging, deploy, login, readme, k8s …) มีคลังในตัว
  (`Detector.knownEnglish`) เพิ่มได้ตามต้องการ
- คำสั้น (≤8 ตัว) ที่หน้าตาเป็นอังกฤษและไม่มีปุ่มสัญลักษณ์ ; ' [ ] , . / - = เลย จะไม่ถูกมองเป็นไทยพิมพ์ค้าง
  (ไทยที่พิมพ์บนคีย์บอร์ดอังกฤษแทบทุกคำจะมีปุ่มพวกนี้ เพราะเป็น ว ง บ ล ม ใ ฝ ข ช)
- ดูเหตุผลที่คำไหนถูก/ไม่ถูกแจ้งได้ด้วย `LazyBoard --verdict <คำ>`

## โหมดอีโมจิ (ปิดอยู่ เปิดในเมนู)

เมื่อเปิด ตอนกด Enter Claude จะเติมอีโมจิที่เข้ากับโทนข้อความ 1–2 ตัวต่อท้ายให้ ถ้าไม่มีอย่างอื่นต้องแก้
จะเติมแล้วส่งให้เองทันที (เห็น ✓) ถ้ามีคำแก้ด้วยจะโชว์คำแก้พร้อมอีโมจิให้กด Tab ตามปกติ
ข้อความที่ลงท้ายด้วยอีโมจิอยู่แล้วจะไม่ถูกเติมซ้ำ Ctrl+Enter ยังส่งตามเดิมไม่เติม

## หน้าตา popup

แคปซูลแก้วเล็กๆ ใต้เคอร์เซอร์ ใช้ Liquid Glass ของระบบ (`NSGlassEffectView`) บน macOS 26 และ vibrancy บนรุ่นก่อน
ตัวหนังสือ 13pt ป้ายคีย์ลัดเป็นปุ่มเล็ก (⇥ ↩ esc) fade เข้าออก 0.12–0.14 วิ
- คำแก้เดียว: เน้นเฉพาะคำที่เปลี่ยนจากที่พิมพ์ (คำเดิมจางลง)
- หลายทางเลือก: ตัดส่วนที่เหมือนกันออก เหลือบริบทสั้นๆ แล้วเน้นเฉพาะคำที่แต่ละแบบต่างกัน จุดสีน้ำเงินคือแบบที่ Tab จะใช้
- กำลังตรวจ: จุด 3 จุดเด้งไล่กัน สีตามธีม / ตรวจผ่าน: ✓

## ข้อจำกัดที่ควรรู้

- ชั้น LLM ส่งข้อความที่พิมพ์ (เฉพาะประโยคล่าสุด) ไปที่ Anthropic API จึงควรปิดในแอปที่อ่อนไหว เช่น ธนาคาร

- ลายเซ็น ad-hoc ผูกกับ identifier (ดู `build.sh`) สิทธิ์ Accessibility จึงคงอยู่หลัง build ใหม่
  ถ้าเคยให้สิทธิ์ build เก่า (ก่อนมีบรรทัดนี้) ให้ `tccutil reset Accessibility com.jeancharairat.lazyboard` แล้วเปิดแอปใหม่
  (แอปเคยชื่อ ThaiTab / `com.jeen.thaitab` สิทธิ์และค่าตั้งค่าของชื่อเก่าถูกย้ายให้ตอนเปิดครั้งแรก ยกเว้นสิทธิ์ Accessibility ที่ต้องติ๊กใหม่)
- log เหตุการณ์ (ไม่มีข้อความที่พิมพ์) อยู่ที่ `~/Library/Logs/LazyBoard.log`
- ช่อง password ดักไม่ได้อยู่แล้ว (secure input ของระบบ) ซึ่งถือว่าดี
- ถ้ากด Enter ส่งข้อความไปก่อน popup จะหายและแก้ย้อนหลังไม่ได้
- ข้อความสั้นมาก (1–2 ปุ่ม) ที่ไม่ใช่คำไทยที่พบบ่อยจะยังไม่ขึ้น popup จนพิมพ์ต่ออีกหน่อย
