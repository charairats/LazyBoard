# LazyBoard 🦥 — ขี้เกียจสลับภาษาโว้ย

ลืมสลับคีย์บอร์ด พิมพ์ผิด ก็แค่กด Caps Lock สลับภาษา คำที่พิมพ์ไปแล้วจะถูกแก้ให้ด้วย

หลักของแอป: **เงียบไว้ก่อน** ไม่เด้ง popup ไม่แย่งปุ่ม Tab ไม่แก้ข้อความเองถ้าไม่ได้ขอ

LazyBoard เป็นแอปเล็กๆ บน menu bar ของ macOS เช่น พิมพ์ `mujgdujp;-hv'` เพราะลืมสลับเป็นไทย
พอกด Caps Lock สลับเป็นไทย มันจะแก้เป็น "ที่เกี่ยวข้อง" ให้ทันที

## มันช่วยอะไรได้บ้าง

| เกิดอะไรขึ้น | LazyBoard ทำอะไร |
|---|---|
| ลืมสลับภาษา (`w,jwfh` แทน ไม่ได้) | กด Caps Lock สลับภาษา แล้วคำที่เพิ่งพิมพ์จะถูกแปลงให้ (เฉพาะเมื่อผลลัพธ์เป็นคำจริง) |
| อยากให้แก้เองโดยไม่ต้องกดอะไร | เปิด "Fix Automatically While Typing" ในเมนู (ค่าเริ่มต้นปิด) |
| พิมพ์ไทยผิดแบบที่เจอบ่อย (เป้น, เเล้ว, นะค่ะ) | แก้ให้เองตอนเคาะ space เมื่อเปิด "Fix Automatically While Typing" |
| พิมพ์ผิดแบบอื่น (อังดฤา, เรยล) | กด Ctrl+Enter ให้ Claude ตรวจ แล้วถามก่อนว่าจะแก้ไหม |
| อยากให้ข้อความดูสุภาพ | เปิดโหมดสุภาพ แล้ว Claude จะเรียบเรียงให้ก่อนส่ง |
| อยากได้อีโมจิท้ายข้อความ | เปิดโหมดอีโมจิ แล้ว Claude จะเลือกให้ 1–2 ตัว |

การแก้ผิดภาษาทำงานในเครื่อง ไม่ต้องต่อเน็ต ส่วนที่บอกว่าใช้ Claude ต้องมี Claude Code หรือ API key

## เริ่มใช้

```bash
./build.sh
```

```bash
open build/LazyBoard.app
```

ครั้งแรกระบบจะขอสิทธิ์ **Accessibility** ให้ไปเปิด LazyBoard ที่
System Settings → Privacy & Security → Accessibility แล้วแอปจะเริ่มทำงานเอง

จากนั้นก็พิมพ์ไปตามปกติ ตั้งค่าทุกอย่างได้จากไอคอนคีย์บอร์ดสายฟ้าบน menu bar

## ปุ่มที่ควรรู้

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| **Caps Lock (แตะ)** | สลับ ไทย/อังกฤษ และแปลงคำที่เพิ่งพิมพ์ผิดภาษาให้ด้วย |
| **Caps Lock (กดค้าง 0.4 วิ)** | เปิด/ปิดตัวพิมพ์ใหญ่ |
| **Backspace** ทันทีหลังถูกแก้ | เอาข้อความเดิมกลับมา และจำไว้ว่าจะไม่แปลงคำนั้นอีก |
| **Enter** | ส่งเลยตามที่พิมพ์ ไม่ถูกหน่วง |
| **Ctrl+Enter** | ให้ Claude ตรวจก่อน แล้วค่อยส่ง |
| **Tab** | เป็นของแอปที่ใช้อยู่เสมอ ยกเว้นตอนมีคำแก้ของ Claude (หรือ Hint Popup ที่เปิดเอง) อยู่บนจอ |
| **Esc** | ไม่เอาคำแก้ หรือย้อนการแก้อัตโนมัติ (ภายใน 4 วินาที) |
| **Shift / Cmd / Option + Enter** | ขึ้นบรรทัดใหม่ ไม่ส่ง |

อยากได้แบบเดิม (Enter ตรวจ, Ctrl+Enter ส่งเลย) เลือกได้ที่เมนู "Check Before Send" → "Enter checks · Ctrl+Enter sends as typed"
แบบเดิมจะให้ Claude ตรวจเฉพาะข้อความที่มีคำน่าสงสัย ข้อความที่ทุกคำเป็นคำจริงจะส่งทันที

## ตอนกด Ctrl+Enter จะเกิดอะไรขึ้น

แอปจะยังไม่ส่ง แต่ขึ้นจุดสามจุดเด้งๆ ระหว่างให้ Claude อ่าน ปกติใช้เวลาไม่กี่วินาที แล้วจะเป็นแบบใดแบบหนึ่ง:

- **ไม่มีอะไรต้องแก้:** ขึ้น ✓ แล้วส่งให้เลย
- **มีคำแก้:** popup จะขึ้นเหนือช่องพิมพ์ คำที่เปลี่ยนมีพื้นหลัง กด Tab (หรือคลิกที่คำแก้)
  เพื่อแก้ในช่องพิมพ์ แล้วกด Enter เพื่อส่ง หรือกด Enter เพื่อส่งแบบเดิม หรือกด Esc เพื่อยกเลิก
  คลิกปุ่มใน popup ได้เหมือนกดปุ่มนั้น
- **Haiku ไม่มั่นใจ:** popup จะเรืองแสงระหว่างให้ Opus ตรวจซ้ำ ใช้เวลาเพิ่มอีกไม่กี่วินาที
- **ตรวจไม่ทัน (10 วินาที หรือ 30 วินาทีถ้าเป็น Opus):** แอปจะขึ้น "No answer in time" แล้วให้กด Enter ส่งเอง

ข้อความที่สั้นกว่า 6 ตัวอักษรจะส่งทันทีโดยไม่ตรวจ และถ้าพิมพ์ต่อระหว่างรอ แอปจะยกเลิกการตรวจรอบนั้น
ถ้าเปิดโหมดสุภาพหรืออีโมจิไว้ กด Enter ธรรมดาก็ผ่าน Claude ด้วย เพราะโหมดพวกนี้ต้องให้ Claude เขียนให้

ถ้าอยากให้ตรวจตอนหยุดพิมพ์ด้วย เปิดได้ที่เมนู "Also Suggest While I Type" (ค่าเริ่มต้นปิด: Claude จะไม่พูดอะไรเลยถ้าไม่ได้กด Ctrl+Enter)

## แก้ผิดภาษาทำงานยังไง

แอปดูสิ่งที่พิมพ์ทีละคำอยู่เงียบๆ ไม่แสดงอะไร กฎมีข้อเดียว: จะแปลงก็ต่อเมื่อสิ่งที่พิมพ์ **ไม่ใช่คำจริง**
และแปลงแล้ว **เป็นคำจริง** เท่านั้น (ชื่อไฟล์อย่าง `.secret` หรือคำอังกฤษจริงจะไม่ถูกแตะ)

มี 3 ระดับ เลือกได้ในเมนูหัวข้อ "Wrong Keyboard":

1. **Also Fix the Words I Just Typed** (ค่าเริ่มต้น เปิด) แปลงเฉพาะตอนกด Caps Lock สลับภาษา คือตอนที่คุณขอเอง
2. **Fix Automatically While Typing** (ปิด) แปลงเองตอนเคาะ space หรือ Enter
3. **Show Hint Popup** (ปิด) ขึ้น popup คำแก้ระหว่างพิมพ์ กด Tab เพื่อรับ

ถ้าแปลงผิด กด Backspace ทันที (หรือ Esc ภายใน 4 วินาที) ข้อความเดิมจะกลับมา และคำนั้นจะไม่ถูกแปลงอีก

ถ้า LazyBoard ปิดตัวผิดปกติ ตัวเฝ้าเล็กๆ จะคืน Caps Lock ให้ macOS เองภายใน 1 วินาที ปุ่มจะไม่ค้างใช้ไม่ได้

เมื่อเปิด "Fix Automatically While Typing" คำไทยที่สะกดผิดบ่อยและตัดสินได้แน่ก็แก้ให้เองตอนเคาะ space เหมือนกัน:

- ้ แทน ็ เช่น เป้น → เป็น, เด้ก → เด็ก
- เเ สองตัว → แ
- ๋ แทน ่ เช่น ไม๋ → ไม่
- ค่ะ ต่อท้าย นะ หรือคำถาม เช่น นะค่ะ → นะคะ, มั้ยค่ะ → มั้ยคะ

## โหมดเสริม

ทั้งสองโหมดปิดอยู่ตั้งแต่แรก เปิดได้จากเมนู "Polish on Send" และ "Check Before Send" ต้องไม่ใช่ "Off"

**โหมดสุภาพ** เลือกลงท้ายได้ว่า ครับ หรือ ค่ะ แล้วตอนกด Enter Claude จะเรียบเรียงข้อความให้เหมาะกับที่ทำงาน
เช่น "ส่ง PR มาด่วนเลย รอนานละ" → "รบกวนส่ง PR ให้โดยเร็วด้วยนะครับ รอมาสักพักแล้วครับ"
แอปจะโชว์ให้ดูก่อนเสมอ และไม่ส่งข้อความที่เรียบเรียงใหม่ให้เอง ควรอ่านก่อนส่ง เพราะความหมายอาจเปลี่ยนไปนิดหน่อย

**โหมดอีโมจิ** เติมอีโมจิที่เข้ากับข้อความ 1–2 ตัวต่อท้าย ถ้าไม่มีอย่างอื่นต้องแก้จะเติมแล้วส่งให้เลย
ถ้าข้อความลงท้ายด้วยอีโมจิอยู่แล้วจะไม่เติมซ้ำ

## เชื่อมต่อกับ Claude

เลือกได้ที่เมนู "Connection"

- **Claude Code (ค่าเริ่มต้น):** ไม่ต้องใช้ API key แค่ติดตั้ง Claude Code และ login ไว้ (พิมพ์ `claude` ใน Terminal แล้วสั่ง `/login`)
  การใช้งานจะนับรวมในโควตาของบัญชี Claude
- **Claude API key:** สร้างคีย์ที่ platform.claude.com แล้วใส่ในเมนู "Connection" → "Set API Key…" คีย์จะเก็บใน Keychain ของเครื่อง

โมเดลเริ่มต้นคือ Haiku 5.5 เปลี่ยนเป็น Opus 5.5 ได้ในเมนู "Connection"
และถ้าไม่อยากใช้ Claude เลย ปิด "ใช้ Claude แก้คำผิด" ได้ การแก้ผิดภาษายังทำงานเหมือนเดิม

## เรื่องความเป็นส่วนตัว

- แอปต้องดักคีย์บอร์ดทั้งเครื่องถึงจะทำงานได้ จึงขอสิทธิ์ Accessibility
- ข้อความบรรทัดล่าสุด (ไม่เกินประมาณ 160 ตัวอักษร) จะถูกส่งไปที่ Claude ตอนตรวจ
  ถ้าเป็นแอปที่มีข้อมูลอ่อนไหว เช่น ธนาคาร ให้เลือก "Disable in <app>" จากเมนู
- ระบบป้องกันช่องรหัสผ่านอยู่แล้ว แอปจึงดักข้อความในช่องนั้นไม่ได้
- log ที่ `~/Library/Logs/LazyBoard.log` ไม่เก็บข้อความที่พิมพ์
- แบบทดสอบการพิมพ์เก็บข้อความที่พิมพ์ในแบบทดสอบไว้ที่ `~/Library/Application Support/LazyBoard/typing-test-results.txt`

## ข้อจำกัดที่รู้อยู่

- **popup อาจไม่ขึ้นตรงเคอร์เซอร์ในบางแอป:** เช่น Microsoft Word ไม่บอกตำแหน่งเคอร์เซอร์ popup จึงขึ้นตามตำแหน่งหน้าต่างแทน
- **ส่งไปแล้วแก้ย้อนหลังไม่ได้:** ถ้าข้อความถูกส่งไปก่อน ก็ต้องแก้เองในแอปนั้น
- **คำสั้นมาก (1–2 ตัวอักษร):** ถ้าไม่ใช่คำไทยที่พบบ่อย popup อาจยังไม่ขึ้นจนกว่าจะพิมพ์ต่อ
- **คำที่ยังพิมพ์ไม่จบ:** เช่น `s,fpy` จะยังไม่ถูกแก้ เพราะยังไม่เป็นคำจริง ต้องพิมพ์ครบเป็น `s,fpy'` (หมดยัง)
- **แก้ผิดได้บ้าง:** เช่น `ผ้าไหมค่ะ` จะกลายเป็น `ผ้าไหมคะ` กด Esc ภายใน 4 วินาทีเพื่อย้อนกลับ

## แบบทดสอบการพิมพ์

เลือก "Typing Test…" จากเมนู แล้วพิมพ์ตาม 10 ประโยค ไทยสลับอังกฤษ
ตอนจบจะได้เห็นความถูกต้อง เวลาที่ใช้ และจำนวนครั้งที่แอปช่วยแก้

## สำหรับคนพัฒนา

### ปัญหาที่เจอบ่อย

- **popup ไม่ขึ้นตรงเคอร์เซอร์:** ดูบรรทัด `anchor:` ใน log จะบอกชื่อแอปและวิธีที่ใช้ เรียงจากแม่นไปหยาบ: `caret`, `marker`, `field`, `window`, `mouse`
- **สิทธิ์ Accessibility หลุด:** build ปกติจะไม่ทำให้สิทธิ์หาย แต่ถ้าหายให้สั่ง `tccutil reset Accessibility com.jeancharairat.lazyboard` แล้วเปิดแอปใหม่
- **ย้ายจากชื่อเก่า:** แอปเคยชื่อ ThaiTab ค่าตั้งค่าจะย้ายมาให้เอง แต่สิทธิ์ Accessibility ต้องเปิดใหม่

### คำสั่งทดสอบ

```bash
./build/LazyBoard.app/Contents/MacOS/LazyBoard --test
```

| ตัวเลือก | ใช้ทำอะไร |
|---|---|
| `--test` | รัน self-test ทั้งหมด |
| `--try "ข้อความ"` | ดูว่าตัวแก้ผิดภาษาจะแก้ข้อความนี้ยังไง |
| `--verdict คำ` | ดูเหตุผลว่าทำไมคำนี้ถูกหรือไม่ถูกแก้ |
| `--llm "ข้อความ"` | ส่งข้อความให้ Claude ตรวจจริง |
| `--stats` | สรุปสถิติการใช้งาน 7 วันล่าสุดจาก log (ไม่มีข้อความที่พิมพ์) |
| `--caret` | ดูว่าแต่ละแอปหาตำแหน่งเคอร์เซอร์ด้วยวิธีไหน (ต้องเปิดผ่าน `open build/LazyBoard.app --args --caret` ถึงจะได้สิทธิ์) |

ตัวแปรที่ใช้กับ `--llm` ได้: `LAZYBOARD_BACKEND=api`, `LAZYBOARD_MODEL=claude-opus-5-5`, `LAZYBOARD_EMOJI=1`, `LAZYBOARD_POLITE=ครับ` หรือ `ค่ะ`
